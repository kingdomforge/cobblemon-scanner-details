# Cobblemon Scanner Details

A client-side Minecraft mod by KingdomForge. Extra labels on Cobblemon's Pokédex scanner: shiny, regional and special
forms, color patterns, colored type names and a level color that compares with your party.

Minecraft 1.21.1, Cobblemon 1.8.1 and 1.8.2, Fabric or NeoForge.
